# JobPilot 求职副驾

JobPilot 是一个本地优先的 BOSS 直聘求职客户端 MVP。它把内置浏览器、岗位台账、AI 匹配、招呼语、跟进提醒、面试准备和个人知识库放在同一个桌面应用里。

> 非 BOSS 直聘官方产品。使用者应遵守目标平台规则与当地法律；建议从人工确认模式开始，避免高频操作。

## 当前能力

- 内置 Chromium 浏览器，使用独立且持久化的 BOSS 登录态。
- 独立全屏登录窗口，与主界面共享 Cookie。
- 浏览器专注模式和 60%-120% 页面缩放。
- 从当前职位列表采集岗位，并按岗位、城市、薪资和排除关键词过滤。
- 本地规则初筛，也可调用 OpenAI 兼容模型完成匹配评分。
- 四种发送策略：仅草稿、逐条确认、批量确认、高分自动发送。
- 可配置每日上限、随机间隔、执行时段和去重周期。
- 可配置跟进日期、最多跟进次数和跟进发送策略。
- BOSS 对话后台同步、第一人称 RAG 回复、逐条确认发送和非敏感意图自动发送。
- 薪资、到岗、联系方式、面试安排等意图可逐项设置为“自动发送前必须人工确认”。
- 对话发送后按配置自动安排跟进；已结束、人工暂停或敏感会话不会进入自动发送队列。
- 验证码或安全验证检测：自动暂停并保留页面，等待人工完成。
- 本地 RAG：导入 PDF、DOCX、Markdown、TXT、JSON、CSV，切片后使用向量和关键词混合检索。
- 对话模型与向量模型独立配置；内置硅基流动 `BAAI/bge-m3`（1024 维）预设和连接测试。
- 基于实际简历、岗位与检索片段生成面试指南。
- 明确面试邀约自动关联岗位，提取时间、方式和地点线索，并可自动生成包含聊天上下文的面试指南。
- API Key 使用 Electron `safeStorage` 加密保存在系统安全存储中。

## 启动

```bash
npm install
npm run dev
```

生产构建和启动：

```bash
npm run build
npm start
```

## 打包安装包

项目已配置 `electron-builder`，使用 `assets/icons/jobpilot.icns` 和 `assets/icons/jobpilot.ico` 作为应用图标。构建产物写入 `release/`：

```bash
# 当前 macOS 架构的 DMG 和 ZIP
npm run package:mac

# Windows x64 的 NSIS 安装包和 portable 便携版
npm run package:win

# 在具备对应构建环境时一次构建 macOS 与 Windows
npm run package:all
```

当前 electron-builder 版本可在 macOS 上交叉生成 Windows NSIS 和 portable 产物；正式发布前仍应在真实 Windows 环境完成安装、启动和卸载测试。发布给真实用户前还需要分别配置 Apple 和 Windows 代码签名证书。

## 数据迁移

设置中的“数据迁移”提供“导出迁移文件”和“选择迁移文件”。迁移文件是本地 JSON，包含岗位、对话、发送历史、知识库切片/向量、候选人画像、简历诊断、面试准备和自动化配置。导入前会自动把当前 `state.json` 备份到当前设备的 `userData/migration-backups/`。

以下内容不会进入迁移文件，也不会跨系统复制：

- 模型 API Key、Embedding API Key、Webhook 密钥（使用系统 `safeStorage` 加密）。
- BOSS 持久化登录态和 Cookie。
- 简历、知识库原文件的本机绝对路径。

同一台 Mac 上从源码版切换到安装版会继续使用 `jobpilot-desktop` 的 `userData` 命名空间，现有数据和 BOSS 登录态可以直接复用。Mac 与 Windows 之间导入后，需要在新设备重新配置模型/向量/Webhook、重新登录 BOSS，并重新选择本机的简历和知识库原文件；已导入的切片和向量仍可直接用于检索。

## 第一次使用

1. 打开“设置”，确认目标岗位、城市、薪资、发送策略和限额。
2. 配置 OpenAI 兼容接口的 Base URL、模型名称和 API Key。
   向量模型可单独选择“硅基流动”，填写独立 Key 并测试连接。
3. 在“岗位雷达”点击“全屏登录”，完成 BOSS 登录后关闭登录窗口。
4. 回到岗位雷达刷新页面，打开职位列表并点击“采集当前页”。
5. 先使用“仅生成草稿”或“逐条确认发送”验证岗位筛选和文案质量。
6. 在“知识库问答”导入项目补充、常见问答口径等资料。

## 默认求职配置

- 岗位：产品经理、AI 产品经理
- 城市：成都
- 薪资：10-20K
- 自动发送阈值：82 分
- 每日上限：20 条
- 随机间隔：45-120 秒
- 去重周期：90 天
- 跟进节点：发送后第 3、7 天，最多两次

这些值都可以在客户端设置页修改。

## RAG 说明

知识库采用适合个人资料规模的轻量方案：

1. 文档在本机解析为纯文本。
2. 按可配置字符数和重叠量切片。
3. 有 Embedding 接口时生成向量；接口不可用时自动退回关键词检索。
4. 查询时混合计算向量相似度和关键词重合度。
5. 只把 Top-K 命中片段发给聊天模型。

知识库原文、切片、向量和聊天记录保存在 Electron 的本地 `userData` 目录中，不写入项目代码。

## 安全边界

- JobPilot 不绕过验证码，也不提供规避站点访问控制的实现。
- 检测到验证码、安全验证或访问异常时会暂停自动化，等待人工接管。
- 自动任务总开关默认关闭；首次招呼、对话回复和到期跟进分别配置发送策略。
- 所有客户端发送共用每日上限、随机间隔和执行时段，发送结果无法确认时暂停对应会话。
- 首次使用建议采用逐条确认，确认筛选和文案质量后再开启高分自动发送。
- 岗位描述和聊天内容均按不可信输入处理，不允许其中的指令覆盖系统提示。
- 模型不得编造候选人的经历、数据或技能；知识库没有答案时应请求本人确认。
- 浏览器自动化可能受到 BOSS 页面更新、访问频率限制或服务规则影响，请低频、个人用途使用。

## 项目结构

```text
electron/       Electron 主进程、加密存储、模型接口、RAG
shared/         配置、状态和候选人画像类型
src/            React 客户端、BOSS 页面脚本与视觉样式
dist/           Vite 前端构建产物
dist-electron/  Electron 主进程构建产物
```

## 当前 MVP 限制

- BOSS 页面 DOM 变化后，采集和发送选择器可能需要更新。
- 系统 Chrome 模式目前只负责兼容性回退，不支持页面自动采集。
- BOSS 页面 DOM 变更可能导致会话定位或发送确认失败；失败时客户端会保留草稿并暂停对应会话。
- 当前产物未签名；macOS 首次打开可能需要在系统设置中允许应用，Windows 发布版也建议配置代码签名。
